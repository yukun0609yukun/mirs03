# mirs03 - 自律走行ロボット開発プロジェクト

沼津工業高等専門学校 電子制御工学科の「実習」において開発している、自律走行ロボット **MIRS (Micro Mouse Intelligent Robot System)** のリポジトリです。

## 概要
本プロジェクトでは、株式会社明電舎との連携を通じ、実社会の課題解決を視野に入れた自律走行ロボットの開発に取り組んでいます。

- **現在のステータス:** 企画・基本設計フェーズ（明電舎様との連携内容を検討中）
- **チーム名:** (ここにチーム名を入力)
- **開発ドキュメント:** [MIRS26SF ドキュメントサイト](https://www2.denshi.numazu-ct.ac.jp/mirsdoc2/mirs26sf/)

## 開発の背景と目的
明電舎の持つインフラ技術やAGV（無人搬送車）の知見を参考にしつつ、以下の技術的課題の克服を目指しています。
1. **高精度な自己位置推定:** センサーフュージョンを用いた環境認識
2. **最適経路計画:** 障害物を回避しつつ目的地へ到達するアルゴリズムの構築
3. **信頼性の高い制御:** 実用性を考慮した駆動系の設計

## 開発環境
- **OS:** WSL2 (Ubuntu 22.04 LTS)
- **制御基板:** Arduino UNO R3 / Raspberry Pi (予定)
- **開発言語:** C++ / Python
- **バージョン管理:** Git / GitHub
