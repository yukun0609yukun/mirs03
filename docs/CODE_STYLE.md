# Code Style

このプロジェクトで推奨する基本的なコーディング規約です。

## 命名規則

- ファイル名: 小文字、アンダースコア区切り (例: vel_ctrl.ino)
- 関数名: snake_case (例: vel_ctrl_execute)
- 型名: suffix `_t` を使用 (例: run_state_t)
- 定数: 大文字スネークケース (例: T_CTRL)

## 関数設計

- 単一責任: 1 関数は 1 つの責務に集中する
- グローバル変数は最小限に抑え、必要な場合はモジュール内で static にする
- 副作用は明確にする（例: motor_set はハードウェアに出力する）

## エラーハンドリング

- Arduino 側: 可能な限り戻り値でエラーを返す設計に
- Raspberry Pi 側: エラー時は -1 を返し、呼び出し元で適切にログ出力

## コメント

- 関数ヘッダに短い説明、引数、戻り値を記載
- 複雑なロジックには「なぜ」その実装なのかを説明するコメントを追加

## フォーマット

- インデント: タブまたはスペース (プロジェクト内で統一)
- 行長: 120 文字以内推奨
